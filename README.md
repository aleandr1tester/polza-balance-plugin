# dsh-polza-balance

Виджет баланса polza.ai для Web GUI DeepSeek Harness: карточка, которую можно **перетаскивать** мышью.

```
● polza.ai                     ⟳ ⚙
БАЛАНС                135,00 ₽
Полный баланс         140,91 ₽
Зарезервировано         5,91 ₽
Потрачено за сутки     98,09 ₽
Всего потрачено       160,08 ₽
```

Строки `Полный баланс` и `Зарезервировано` — парные и по умолчанию скрыты: обе появляются, когда резерв больше нуля, и обе скрываются, когда холда нет. В настройках у каждой есть своя галка «Всегда показывать», чтобы держать строку на карточке постоянно.

Суммы печатаются как `1'236,36 ₽`: разделитель тысяч — апостроф, десятичный — запятая, всегда два знака после запятой.

## Что показывает

| Строка | Источник | Смысл |
|---|---|---|
| `Баланс Z ₽` | `get_balance` (`available`) | чем реально можно пользоваться: баланс минус зарезервированное (и минус остаток лимита участника, если он задан) |
| `Полный баланс W ₽` | `get_balance` (`balance`) | весь остаток на счёте, включая зарезервированное; по умолчанию появляется только вместе с «Зарезервировано» (при `R > 0`) или всегда при включённой галке в настройках; сумма выводится синим |
| `Зарезервировано R ₽` | `get_balance` (`reservedAmount`), резерв из `get_balance_details` как fallback | холд под уже запущенные, но не завершённые генерации; показывается при `R > 0` (и всегда, если включена галка в настройках); при `R > 0` сумма красная; появление этой строки тянет за собой «Полный баланс» |
| `Потрачено за сутки X ₽` | `get_transaction_history` | сумма `debit`-транзакций с локальной полуночи |
| `Всего потрачено V ₽` | `get_balance_details` (`spentAmount`) | суммарные списания за всё время |

Отдельного MCP-метода «потрачено за сутки» у polza.ai нет: `get_balance_details` отдаёт только суммарный `spentAmount`, поэтому суточная цифра считается по истории транзакций (см. «Экономия запросов»). Числа всех строк прижаты к правому краю.

Резерв — не потерянные деньги: по завершении генерации он превращается в фактическое списание, остаток холда возвращается в баланс; при ошибке или отмене резерв снимается целиком.

Точка слева — состояние опроса: зелёная — данные свежие, жёлтая — идёт запрос, красная — ошибка (текст ошибки в подсказке). В подсказке: время обновления, полный баланс и, если есть, резерв.

## Управление

| Действие | Что делает |
|---|---|
| **Перетащить карточку** за любое место, кроме кнопок | перемещает виджет; позиция запоминается в `localStorage` (`dsh-polza-balance:position`) и восстанавливается после перезагрузки |
| **Клик** по карточке | принудительно обновить данные |
| **⟳** в шапке | принудительно обновить данные (то же, что клик, но не сдвигает виджет) |
| **⚙** или двойной клик | панель настроек |
| Наведение | подсказка: время обновления, доступный остаток, ошибка |

При первом запуске карточка встаёт в левом нижнем углу **над кнопкой профиля/входа** в сайдбаре: положение вычисляется по её реальному `getBoundingClientRect()` (маркер `[data-signed-out]`), поэтому кнопка остаётся кликабельной. Если кнопки на экране нет, используется отступ 96 px от низа. При изменении размера окна позиция прижимается к видимой области; перетащить карточку за пределы экрана нельзя (8 px от края).

## Настройки

- **Токен MCP сервера polza.ai** — тот же токен, что и для MCP (`polza_…`); в репозитории он не хранится — впишите его в настройках карточки (⚙), он сохранится в `localStorage`; в установленной копии профиля токен можно держать в `cordis.patch.yml`;
- **Обновление, сек** — по умолчанию 60 (минимум 15);
- **Всегда показывать «Полный баланс»** — без галки строка появляется вместе с «Зарезервировано» (когда резерв > 0), с галкой видна постоянно;
- **Всегда показывать «Зарезервировано»** — без галки строка появляется только при резерве > 0, с галкой видна постоянно (нулевой резерв показывается как `0,00 ₽` приглушённым цветом, без красного).

Настройки сохраняются в `localStorage` браузера и переживают перезапуск; они перекрывают значения из `cordis.patch.yml`. Дневного лимита в настройках больше нет (см. историю версий).

## Как это устроено

- Пакет одновременно является **bundle** (`dsh.bundle.patch` → `cordis.patch.yml`) и **клиентским плагином** (`dsh.client.platform: "web"`, `exports["./client"]` → `lib/client.js`).
- `lib/index.js` — пустая host-половина: строка Loader'а существует, клиентский модуль отдаётся из `lib/client.js`.
- `lib/client.js` — бандл в формате `window.__ModuleLoader__.load({ id, factory })`; внутри — React-компонент, который регистрируется в слоте `shell.overlay`. Позиция задаётся `position: fixed; left/top` в пикселях, перетаскивание — Pointer Events с `setPointerCapture`, `touch-action: none` и курсором `grab`/`grabbing`.
- Данные читаются напрямую из MCP `https://polza.ai/api/mcp` (`tools/call`), CORS у polza.ai открыт (`access-control-allow-origin: *`), поэтому прокси не нужен.

## Аудит кода

Плагин маленький: вся логика — в `lib/client.js`, а `lib/index.js` только держит плагин в host-ростере (пустой `apply`). Чтобы быстро убедиться, что код чистый:

- **Сеть** — ровно один `fetch` в `mcpCall()`: POST JSON-RPC `tools/call` на `https://polza.ai/api/mcp` (адрес меняется в настройках). Других запросов, картинок, скриптов и телеметрии нет.
- **Хранилище** — только `localStorage` (`dsh-polza-balance:settings`, `dsh-polza-balance:position`).
- **Динамический код** — нет `eval`, `new Function`, `innerHTML`, `document.write`, динамических `import()`.
- **Секреты** — токен хранится локально, отправляется только на настроенный endpoint, показывается только в поле `type="password"`, не логируется и не хранится в репозитории.
- **Данные** — только чтение (баланс, детали баланса, история транзакций); плагин ничего не меняет на счёте.

Быстрая проверка (PowerShell; `Where-Object` отбрасывает строки комментариев, чтобы шапка-карта аудита не попадала в счёт):

```powershell
Select-String -Path lib\client.js -Pattern 'fetch\(' | Where-Object { $_.Line -notmatch '^\s*(//|\*)' }        # один вызов
Select-String -Path lib\client.js -Pattern 'localStorage' | Where-Object { $_.Line -notmatch '^\s*(//|\*)' }   # только настройки/позиция
Select-String -Path lib\client.js -Pattern 'eval|Function\(|innerHTML|document\.write|import\(' | Where-Object { $_.Line -notmatch '^\s*(//|\*)' }   # пусто
Select-String -Path lib\client.js -Pattern 'https?://' | Where-Object { $_.Line -notmatch '^\s*(//|\*)' }      # только endpoint
```

В `lib/client.js` каждый регион помечен `//#region`, каждая функция и каждый элемент интерфейса — комментарием с описанием входов, выходов и побочных эффектов; шапка файла содержит карту аудита.

## Когда обновляется

Три независимых сценария:

1. **По таймеру** — каждые `refreshSeconds` секунд (по умолчанию 60, минимум 15), плюс при возврате на вкладку.
2. **Вручную** — кнопка ⟳ в шапке карточки или клик по ней.
3. **По началу запроса** — плагин подписан на `api-session/status` (running-статус сессий через `ctx.remote.$on`): как только вы отправили сообщение, карточка сразу перечитывает данные, плюс два контрольных дочитывания через 2,5 и 7 секунд — резерв создаётся через мгновение после приёма запроса. Поэтому строка «Зарезервировано» появляется даже с выключенной галкой «всегда показывать», как только данные о холде реально есть.

## Экономия запросов

`get_transaction_history` пагинируется по 50 записей. Полный скан уходит вглубь до начала суток; между сканами виджет дозапрашивает только первую страницу и добавляет новые списания по возрастающим `id`. Полный пересчёт выполняется при загрузке, при смене суток и раз в 5 минут. Итог: 3 запроса в минуту вместо десятка.

Учитываются только `debit`; пополнения (`credit`, депозиты) дневной расход не уменьшают.

## Установка / удаление

Плагин установлен в профиль `desktop` как bundle:

```
dsh plugin --profile desktop add <путь-к-пакету>     # установка (через Plugin Manager)
```

Профиль — `%USERPROFILE%\.dsh\profiles\desktop`: пакет в `dependencies`, имя в `dsh.profile.bundles`, файлы подключены в `node_modules` через pnpm.

- **Отключить**: Settings → Plugins → выключить строку `ui-polza-balance` (или `set_plugin` в Plugin Manager).
- **Удалить**: Plugin Manager → удалить bundle `dsh-polza-balance`.
- **Обновить код**: поднять `version` в `package.json`, затем `remove_bundle` + `install_bundle` (pnpm копирует файлы в стор, правки исходников сами в профиль не попадают).

## Проверка

```
$env:POLZA_TOKEN="polza_…"; node test/smoke.mjs    # регистрация, рендер-дерево, позиционирование/клэмпы, реальный MCP-опрос, инкрементальный расход
node test/render.mjs                               # рендер настоящим React 18 (обе темы), состав строк и отсутствие полей лимита
```

`test/render.mjs` один раз скачивает React в `tmp/react-cache`, дальше работает без сети.

## Ограничения

- «Потрачено за сегодня» — сумма `debit`-транзакций с локальной полуночи; часовой пояс берётся из браузера.
- Токен и позиция хранятся локально (в `cordis.patch.yml` и/или `localStorage`), никуда больше не отправляются.
- Если на аккаунте polza.ai задан лимит расходов участника, `available` из API может быть меньше `balance` — реальный доступный остаток виден в подсказке при наведении на карточку («доступно … руб»).
- Если токен недействителен, карточка остаётся на месте с красной точкой и текстом ошибки в подсказке.
